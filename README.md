# Звуковой барьер — рекордер

Android-приложение на Kotlin, которое:

- записывает звук с микрофона;
- в реальном времени отслеживает самый громкий момент записи (пиковую амплитуду) и показывает, на какой секунде он произошёл;
- когда громкость превышает порог, показывает эффект «звуковой барьер сломан» (вспышка на экране + вибрация);
- позволяет остановить запись и сохранить её кнопкой **«Сохранить»** — файл кладётся в `Музыка/SoundBarrierRecorder` на устройстве (через `MediaStore`, без лишних разрешений на Android 10+).

## Как получить APK

В этом архиве — **исходный код проекта** (Android Studio / Gradle), а не скомпилированный APK: сборка Android-приложений требует Android SDK и загрузку зависимостей из интернета, чего нет в среде, где я готовил файлы. Есть два простых способа получить готовый `.apk`:

### Вариант 1 — GitHub Actions (ничего устанавливать не нужно)
1. Создайте новый репозиторий на GitHub и загрузите туда содержимое этого архива (или распакуйте и сделайте `git push`).
2. В репозитории уже лежит workflow `.github/workflows/build.yml`.
3. После пуша он автоматически соберёт `app-debug.apk` — скачать его можно во вкладке **Actions → (последний запуск) → Artifacts**.

### Вариант 2 — Android Studio
1. Откройте папку проекта в Android Studio (Open → выбрать эту папку).
2. Дождитесь синхронизации Gradle (потребуется интернет для загрузки зависимостей).
3. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
4. Готовый файл будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Разрешения
Приложению нужен доступ к микрофону (`RECORD_AUDIO`) — при первом запуске появится системный запрос.

## Примечания
- Минимальная версия Android — 7.0 (API 24).
- Порог «звукового барьера» задан в коде (`barrierThreshold` в `MainActivity.kt`, значение `24000` из максимума `32767`) — при желании его легко подправить.
